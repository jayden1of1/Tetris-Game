# Tetris Game
 
Overview
A classic implementation of the popular puzzle game Tetris. This project features falling tetrominoes that players must arrange to create complete rows, which then disappear to make room for more pieces.
Features

Seven different tetromino shapes (I, J, L, O, S, T, Z)
Score tracking system
Level progression with increasing difficulty
Preview of the next piece
Game over detection


How to Play

Use the arrow keys to move the tetromino:

Left Arrow: Move left
Right Arrow: Move right
Down Arrow: Soft drop (move down faster)
Up Arrow: Rotate clockwise


Space Bar: Hard drop (instantly drop the piece)
P: Pause/Resume the game
The game ends when the stack of tetrominoes reaches the top of the playing field
